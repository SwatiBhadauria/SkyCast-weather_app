# ☁️ SkyCast — Weather App

**Your world, at a glance.**

SkyCast is a responsive weather application built using HTML, CSS, and JavaScript. It allows users to search for a city and view its current weather conditions through a simple, clean, and user-friendly interface.

## ✨ Features

- 🌍 **City Search:** Search for weather information by city name.
- 🌡️ **Current Temperature:** View the current temperature in Celsius.
- 🌤️ **Weather Conditions:** See conditions such as clear skies, clouds, rain, and snow.
- 💧 **Humidity:** Check the current relative humidity.
- 🌬️ **Wind Speed:** View the current wind speed.
- 🌡️ **Feels Like:** Check the apparent temperature.
- 📱 **Responsive Design:** Enjoy a user-friendly layout on desktop and mobile devices.
- ⚡ **Live Weather Data:** Fetch current weather information using the Open-Meteo API.

## 🛠️ Technologies Used

- **HTML5** — Structures the application.
- **CSS3** — Provides styling, layout, and responsive design.
- **JavaScript** — Handles city searches, API requests, and dynamic updates.
- **Open-Meteo API** — Provides geocoding and weather forecast data.
- **Git & GitHub** — Version control and project hosting.
- **GitHub Pages** — Website deployment.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SwatiBhadauria/SkyCast-weather_app.git
```

### 2. Open the project

```bash
cd SkyCast-weather_app
```

Open the folder in Visual Studio Code.

### 3. Run the application

Open `index.html` using the Live Server extension in VS Code.

Alternatively, open `index.html` directly in your browser.

**Note:** An internet connection is required to retrieve weather data from the API.

## 🔌 API Information

SkyCast uses the [Open-Meteo API](https://open-meteo.com/) to retrieve city coordinates and current weather information.

The application uses:
- **Geocoding API** to find a city's location.
- **Forecast API** to retrieve current temperature, humidity, apparent temperature, weather codes, and wind speed.

No API key is required for typical non-commercial use.

## 🎯 Project Objective

The objective of SkyCast is to demonstrate the practical use of HTML, CSS, JavaScript, asynchronous API requests, and dynamic DOM manipulation by building a functional weather application.
